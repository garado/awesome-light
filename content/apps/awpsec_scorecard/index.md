Minimal baseball scores for android, built for the Light Phone III.

Scorecard is written in Kotlin with Jetpack Compose and Material3 primitives. It uses the public MLB Stats API, with no account system, ads, analytics, or API keys. The interface is intentionally black-and-white, low-motion, and low-data friendly.

## Features

- Today's MLB slate with live, upcoming, and final games
- Live pitch/count/base state and box score
- Pregame probable pitchers and lineups
- Final linescore and player stat lines
- Favorite teams, low data mode, background refresh, keep-awake option
- Standings and player stat search
