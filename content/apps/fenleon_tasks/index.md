A calm, local-first task list built with the Light SDK. Add tasks, file them into
categories, check them off, and optionally set a due date and time. The whole
list lives in one small JSON file on the device — no account, no network, no
sync. Unlike cloud-backed task apps, everything stays on the phone.

## Features

- **Views**: All, Inbox, Planned, and Completed, plus your own categories — the selected view's name sits in the top bar.
- **Planned**: due tasks grouped under Overdue, Due Today, and Upcoming, with a one-tap Due Today filter.
- **Due dates with an optional time**, picked from a minimal month-grid calendar.
- **Categories**: file tasks away, rename or delete them from the categories panel (deleting a category moves its open tasks to the Inbox).
- **Calm interactions**: one tap checks a task off; details are read-only; the interface is pure monochrome Light design.
- **Zero permissions**: Tasks holds no permissions and never touches the network.
