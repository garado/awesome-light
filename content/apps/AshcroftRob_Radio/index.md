# Radio
Built with the Light Phone SDK. This tool allows users to discover, play, and curate their favorite online radio stations.

## Features
- **Live Streaming**: High-quality audio playback.
- **Background Playback**: Continues playing audio even when the tool is minimized or the screen is off.
- **Station Search**: Discover thousands of stations globally using keywords, station name, or stream IP address
- **Library Management**: Curate Favourites and track listening history.
